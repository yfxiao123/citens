# 硕士学位论文开题报告（完整草稿）

**论文题目**：玻璃盒机器学习与中国 A 股股票收益预测研究——基于可解释提升机（EBM）的复现与本土化拓展

**题目来源**：导师指导下，阅读文献并结合实际产生的自主选题。

**题目类型**：资本市场与金融工程研究（机器学习方法在实证资产定价中的应用）。

---

## 一、研究背景

2023 年 10 月召开的中央金融工作会议提出"加快建设金融强国"，并将"全面加强金融监管、有效防范化解金融风险"列为重点任务①。随着量化投资在 A 股的规模持续扩张，模型驱动交易的市场影响与透明度问题上升为监管核心议题：中国证监会于 2024 年 5 月发布《证券市场程序化交易管理规定（试行）》，要求程序化交易投资者报告账户、资金与交易策略信息，沪深北交易所随后出台配套实施细则②。监管脉络清晰地指向同一个问题——量化模型的"可审计性"：当越来越多的定价与交易决策由统计学习模型做出时，模型内部逻辑能否被外部观察与检验，直接关系到监管要求能否落地、系统性风险能否被事前识别。

产业实践同样在呼唤可解释性。国内量化私募管理规模已逾万亿元（具体数字以中国证券投资基金业协会最新年报为准③），机器学习模型已成为头部机构的标准化工具。2024 年初的微盘股流动性事件提供了一个现实的警示样本：小市值股票连续回调、雪球结构产品集中敲入、量化中性产品净值大幅回撤，个别头部量化私募因开盘瞬间大额集中卖出被交易所限制交易④。事后复盘普遍将同质化因子与相似的模型结构列为波动的放大器——大量"黑盒"模型在相近的信息集上做出同向决策，而其风险的积累过程无法从事前被观察、被审计。在此意义上，模型可解释性已不是学术审美问题，而是关系到市场微观结构稳定的现实问题。

与监管与产业的诉求相呼应，学术研究正处在"精度—可解释性"权衡被打破的临界点上。机器学习收益预测经过十余年发展已成实证资产定价的主流范式：Gu、Kelly 和 Xiu（2020）在美股上系统比较了从线性正则化到神经网络的十余种方法，证明非线性与特征交互是样本外可预测性的主要来源；Leippold、Wang 和 Zhou（2022）将这一范式完整移植到 A 股，发现机器学习在散户主导的 A 股预测力更强、流动性类特征居于主导。然而，预测精度最高的模型（深度网络、大规模集成树）恰恰最不透明，从其系数或结构中读不出经济学含义。Rudin（2019）系统论证了这一权衡可以被打破：对高风险决策应直接使用内在可解释的"玻璃盒"模型，而非对黑盒做事后解释。Bell、Kakhbod、Lettau 和 Nazemi（2026）在《Journal of Financial Economics》首次将可解释提升机（Explainable Boosting Machine, EBM）引入收益预测：在美股公司债市场上，EBM 的样本外 R²（12.10%）与随机森林（12.54%）相当，而最重要的预测变量（不确定性变化）与最重要的交互项（"不确定性变化 × 信用利差"）都能从显式形状函数中直接读出——机器学习预测第一次同时具备了精度与经济学可读性。

然而，Bell 等（2026）的全部证据仅覆盖美国公司债市场。本研究拟将其玻璃盒范式迁移至中国 A 股，聚焦三个递进的问题：其一，EBM 的精度优势在散户主导、政策驱动的 A 股横截面上是否成立；其二，A 股收益生成的非线性与交互结构能否被形状函数显式读出——特别地，在政策敏感性更强的中国市场，不确定性变量与个股特征的交互是否存在、方向如何；其三，读出的结构能否支持符合 A 股制度约束（卖空受限、涨跌停）的可执行组合。需要说明的是，本研究以 A 股而非中国公司债为迁移落点，原因在于后者缺乏 TRACE 等价的逐笔成交数据、市场流动性有限且以估值驱动定价，收益预测研究的数据基础不成立；而 A 股拥有 Leippold、Wang 和 Zhou（2022）验证过的 94 特征管线与成熟的本土因子体系（CH-3/CH-4），是玻璃盒范式最可防御的迁移对象。

## 二、研究意义

### （1）理论意义

第一，检验玻璃盒范式的跨市场稳健性。"EBM 精度不输黑盒"的命题目前只有美国公司债一例证据；A 股散户主导、流动性驱动、政策敏感的市场结构，构成对该命题远比美股更严苛的测试环境。若命题在 A 股成立，则"精度—可解释性权衡不可逾越"的传统认识在股票与债券两大资产类别上都被推翻；若不成立，其边界条件本身也是重要知识。本研究将为这一检验提供首个 A 股证据。

第二，提供不确定性定价的 A 股微观证据。不确定性度量文献（Jurado、Ludvigson 和 Ng，2015；Baker、Bloom 和 Davis，2016；Huang 和 Luk，2020）与机器学习定价文献（Gu、Kelly 和 Xiu，2020；Leippold、Wang 和 Zhou，2022；Bell 等，2026）长期平行发展，唯一的交汇点是美国公司债市场。中国市场为二者的接通提供了独特场景：政策不确定性对企业行为的实质性影响已被中文文献证实（张成思和刘贯春，2018；顾夏铭等，2018），但它是否进入 A 股的收益生成过程、是否与个股特征交互、是否被散户结构放大，均无答案。本研究通过自建中国版不确定性指数并将其纳入高维交互框架，直接回答这一开放问题。

第三，为可解释机器学习的方法论提供补充。Bell 等（2026）未给出交互效应的标准显著性检验，本研究构造"bootstrap 置信带 + 消融增量 R² + 排序组合检验"的三重流程，可为后续玻璃盒定价研究复用；同时在中国样本上对照 EBM 显式结构与 SHAP 事后归因的差异，为 Rudin（2019）"事后解释不可靠"的论断提供新增经验证据。

### （2）现实意义

第一，为量化投资的模型透明化提供范式。监管对程序化交易的报备与检查要求，使模型可审计性成为合规刚需；玻璃盒模型"预测即解释"的特性——每个特征的边际贡献有显函数、可绘图、可置信区间——直接契合这一监管方向，为机构提供了一条兼顾精度与合规的技术路线。

第二，为无法卖空的长线资金提供可落地工具。A 股融券供给有限且成本高企，美式研究惯用的多空组合对公募、保险、银行理财等资金并不可执行。本研究设计的多头指数增强组合与 EBM-pos 择时策略只依赖做多与现金切换，检验标准为扣除费用后的净超额收益，对长线资金具有直接可用性。

第三，不确定性指数与择时信号具有市场风险预警含义。自建的中国宏观与金融不确定性指数若被证明含有收益预测信息，可作为投资者情绪与风险环境的监测变量，为逆周期监测与投资者保护提供参考。

## 三、国内外研究现状及分析（文献综述）

机器学习方法为资产收益预测带来了精度的跃升，却同时带来了"黑盒"之困；本研究拟复现并拓展的玻璃盒机器学习框架（Bell 等，2026）正处在这两条文献线的交汇处。下文依次从四个方面进行综述：一是资产收益预测的机器学习方法研究，梳理该范式从股票市场到债券市场的演进脉络；二是机器学习模型的可解释性研究，论证选择玻璃盒模型的必要性；三是宏观经济不确定性的度量研究，为核心预测变量提供度量基础；四是中国 A 股市场的收益可预测性与制度环境研究。在此基础上进行文献述评，归纳现有研究的空白与本文的切入点。

### （一）资产收益预测的机器学习方法研究

资本市场如何为资产定价，是金融学最核心的经验问题。沿着 Fama（1970）有效市场假说开辟的传统，实证资产定价长期依赖线性因子模型：Fama 和 French（1993）将市场、规模与价值因子确立为横截面收益的标准解释框架，五因子模型（Fama 和 French，2015）进一步纳入盈利与投资因子。然而，随着学术界积累的异象变量越来越多——Harvey、Liu 和 Zhu（2016）统计的公开发表异象数量已逾三百——实证资产定价进入了"因子动物园"时代。当成百上千个候选特征同时摆在研究者面前时，传统计量工具的局限暴露无遗：经典最小二乘法在高维环境下极易产生多重共线性与过拟合，样本外预测能力急剧退化；研究者手工挑选因子的做法也难以回避数据窥探偏差。方法论上的这一困境，构成了机器学习进入收益预测领域的直接动因。

第一代进入资产定价的机器学习方法是带惩罚项的线性模型。LASSO 通过 L1 范数惩罚将无关变量系数压缩为零，实现变量选择；岭回归以 L2 范数压缩参数；弹性网络则兼顾两者。Feng、Giglio 和 Xiu（2020）将 LASSO 型双正则化嵌入因子甄别流程，给出了对新因子边际定价能力的稳健检验。与之并行的是降维与潜因子方法：Kelly 和 Pruitt（2015）提出的三阶段回归滤子转而最大化潜在因子与预测目标的协方差，Kelly、Pruitt 和 Su（2019）的特征协方差模型（IPCA）进一步让因子载荷成为公司特征的函数，将"特征"与"协方差风险"统一在一个框架内。

真正带来范式转变的是非线性模型。以随机森林（Ho，1995）为代表的装袋树与以 XGBoost（Chen 和 Guestrin，2016）为代表的梯度提升树通过树结构自然捕捉特征交互；Bryzgalova、Pelger 和 Zhu（2025）提出的资产定价树让分组本身成为数据的函数，Cong 等（2025）的面板树则在面板结构上直接构造有效前沿。神经网络方面，Gu、Kelly 和 Xiu（2021）用自编码器同时估计定价误差与潜在因子，Chen、Pelger 和 Zhu（2024）以生成对抗网络刻画条件因子动态。这一方法族的首场系统性"赛马"由 Gu、Kelly 和 Xiu（2020）完成：他们以美股 94 个特征、逾六十年月度样本比较了从线性正则化到五层神经网络的十余种方法，发现树模型与神经网络的样本外 R² 显著更高，且增益主要来自允许**非线性与特征交互**——传统线性模型的样本外预测甚至不敌"零预测"基准。Freyberger、Neuhierl 和 Weber（2020）以非参数方法刻画特征与收益的函数形状，证明多数特征的影响呈高度非线性；Kozak、Nagel 和 Santosh（2020）从随机贴现因子贝叶斯收缩的角度得出一致判断：放弃非线性会显著损失定价精度。

这场赛马随即引发了跨市场的复制与拓展浪潮。李斌等（2019）构建了 12 种机器学习算法驱动的 A 股收益预测模型，发现深度网络的样本外表现最优，是中文文献中最早的系统证据。Leippold、Wang 和 Zhou（2022）将该范式完整移植到 A 股：基于 CSMAR 数据构建 94 个公司特征，发现机器学习在 A 股的样本外预测力显著强于美股，且特征重要性格局迥异——以换手率、短期反转为代表的流动性类特征居于主导，动量的重要性远低于美股，作者将其归因于散户主导与做空受限的市场结构；其姊妹篇（Leippold 等，2020）进一步将中国信号库扩展至 1160 个，系统检视"中国因子动物园"中哪些信号在机器学习框架下仍然存活。Hanauer 和 Kalsbach（2023）将比较扩展至新兴市场整体，同样发现非线性与交互带来经济上可观的样本外收益；Zhang（2026）则细化了线性模型与树模型的适用边界，指出在低维因子集下两类模型的绩效差异具有明确的条件依赖性。

方法与市场维度成熟的另一面，是预测对象向固定收益市场的延伸——这也是本研究拟复现的源论文所在的分支。Bianchi、Büchner 和 Tamoni（2021）率先将机器学习系统性地用于债券风险溢价预测，发现无论美国国债还是公司债，样本外可预测性都显著强于股票市场。数据基础方面，Kelly、Palhares 和 Pruitt（2023）基于 TRACE 逐笔交易数据构建了公司债收益与特征的标准数据集，并证明常见公司债特征在线性框架下解释力有限，而允许特征交互的树模型能大幅提升拟合——与股票市场"交互即预测力"的结论遥相呼应。Bali 等（2022）将默顿结构模型的违约距离变量与机器学习结合；Dickerson 等（2023a）以贝叶斯方法梳理了公司债"因子动物园"，Dickerson 等（2023b）区分了债券市场被定价的风险来源，其后续工作（Dickerson 等，2023c）还揭示了基于 TRACE 价格构造的信号普遍含有微观结构噪声、需专门调整才能避免虚假可预测性——这对任何使用交易所汇总价格数据的研究（包括中国市场的日线数据）都有方法论警示意义。Binsbergen 等（2025）与 Bartram 等（2025）分别发展了久期基础的债券估值框架与错误定价检验。中国债券市场的机器学习研究起步较晚且集中于信用风险方向（Lu 和 Zhuo，2021；Geng，2024）。

当然，这一范式的方法论根基并非没有争议。Harvey、Liu 和 Zhu（2016）提醒学界，数百个公开发表的异象很大程度上是同一批历史数据被反复搜寻的产物，多重检验使多数"发现"的统计显著性被系统性高估，他们据此主张将新因子的显著性门槛提高到 t 值 3.0 以上；与之相关的另一重质疑落在经济显著性上——统计上成立的预测力未必能承受高换手带来的交易成本侵蚀，而机器学习框架下最重要的预测特征恰恰常是换手率、短期反转一类高换手变量（Leippold、Wang 和 Zhou，2022）。就此而言，严格的样本外滚动验证与"预测力能否转化为扣除成本后的组合净收益"，共同构成检验这一范式可信度的两条纪律，本文的复现设计也将遵循这两条纪律。

至此，这条文献线给出三个稳定的结论：其一，机器学习收益预测的方法体系已经成熟，从美股到 A 股再到新兴市场与债券市场证据一致；其二，**非线性与特征交互是样本外可预测性的主要来源**；其三，可预测性的量级因资产而异——股票月度样本外 R² 通常不足 1%，债券市场则可达百分之十量级。但一个日益凸显的问题是：预测精度最高的模型（深度网络、大规模集成树）恰恰是最不透明的，其经济学解释力严重受限。这一"精度—可解释性"的张力，构成了下一条文献线的起点。

### （二）机器学习模型的可解释性研究：从事后解释到玻璃盒模型

机器学习模型的"可解释性"，指模型的预测逻辑能够被人类直接理解、检验与审计的程度；按实现路径，学界将其区分为两条路线——对已训练好的黑盒模型附加近似解释的"事后解释"，与预测结构本身即可直接读取的"内在可解释"（玻璃盒）建模。金融研究中可解释性的价值由来已久：资本定价理论的生命力正在于其系数与结构可以被赋予经济学含义，而这一传统在深度模型时代受到直接冲击。应用层面的主流应对是事后解释（post-hoc explainability）：Lundberg 和 Lee（2017）提出的 SHAP 值将合作博弈论的 Shapley 值引入预测归因，成为事实标准；Lundberg 等（2020）进一步给出面向树模型的高效精确算法 TreeSHAP，使其在金融研究中大规模可用。然而，事后解释本质上只是用一个简化模型去**近似**黑盒模型的行为，近似质量本身不可验证。Rudin（2019）在《Nature Machine Intelligence》上系统论证：对高风险决策而言，这种近似既不必要也不可靠，应直接使用内在可解释（inherently interpretable）的"玻璃盒"模型。Slack 等（2020）以对抗实验证明 LIME 与 SHAP 的解释可以被系统性操纵而不被察觉；Molnar 等（2020）归纳了模型无关解释方法的一般性陷阱。这些批评直指金融机器学习研究的软肋：以 SHAP 值"解读"黑盒模型所得出的经济结论，可能只是近似器的产物而非市场自身的结构。

与"事后解释"路线相对，"内在可解释"路线在统计学习中有深厚根基。Hastie 和 Tibshirani（1986）提出的广义可加模型（GAM）将条件期望写成各特征一元函数之和，每个特征的边际贡献因此具有显式函数形式；Lou 等（2013）为 GAM 引入成对交互项（GA2M），使关键的二阶交互同样可显式表示，且精度逼近完全黑盒模型。Nori 等（2019）在微软研究院的 InterpretML 框架中将循环梯度提升、多层装袋与快速交互检测算法（FAST）结合，形成可解释提升机（Explainable Boosting Machine, EBM）：模型整体是"截距 + 各特征阶跃函数 + 选定交互对的二维阶跃函数"的加法结构，预测精度与随机森林、XGBoost 相当，而每个形状函数都可以直接读取、绘图并给出置信区间。EBM 已在刑事司法再犯预测（Wang 等，2023）、基因诊断（Wagner 等，2023）与信贷回收率预测（Nazemi 和 Fabozzi，2024）等高风险场景得到验证，但在金融资产定价领域的应用长期空白。

Bell、Kakhbod、Lettau 和 Nazemi（2026）发表于《Journal of Financial Economics》的《Glass Box Machine Learning and Corporate Bond Returns》填补了这一空白，也是本研究拟复现的对象。作者以 2002 年 7 月至 2020 年 8 月美国公司债市场 1207 家发债企业、81 个预测变量（41 个企业特征与 40 个市场、宏观变量）的月度面板为样本，首次将 EBM 用于横截面收益预测。核心发现有三：其一，**精度几乎无损失**——EBM 样本外 R² 达 12.10%，与随机森林（12.54%）相当、超过 XGBoost（11.36%），显著优于 LASSO（7.99%）；其二，**经济结构可直接读取**——最重要的预测变量并非企业特征，而是金融不确定性变化（ΔUNCf）、宏观不确定性变化（ΔUNC）与期限结构因子（TERM）：TERM 仅在分布右尾抬升未来收益约 100 个基点，呈显著不对称性；最重要的交互项为"不确定性变化 × 信用利差"，含义是当不确定性回落时高利差债券存在超额的价格修复；其三，**可解释性具有组合价值**——按预测收益构造的十分位多空组合夏普比率达 0.38—0.40，超过所有特征组合基准；形状函数支持"事前"刻画组合特征，并催生了在预测收益为负时转入无风险资产的择时策略（EBM-pos），在金融危机与新冠疫情期间有效规避回撤。作者最后通过蒙特卡洛模拟证明，EBM 的显式交互函数比 SHAP 事后归因更准确地还原真实的数据生成过程——为 Rudin（2019）的论断提供了资产定价领域内的直接证据。

值得注意的是，Bell 等（2026）的全部证据仅覆盖美国公司债市场。EBM 玻璃盒框架是否适用于散户主导、政策驱动更强的 A 股，其揭示的"不确定性—特征交互"结构是否存在中国版本，完全未有研究涉及——这正是本研究的问题所在。而要回答其中关于不确定性的部分，必须先厘清不确定性变量自身的度量传统。

### （三）宏观经济不确定性研究：预测变量的度量基础

本研究单独梳理这支文献，并非出于宏观经济学的兴趣，而是因为不确定性变量在收益预测中扮演的角色发生了实质变化：在 Bell 等（2026）的模型中，不确定性变化是超过一切公司特征的第一梯队预测变量，且与个股特征的交互项贡献了相当一部分拟合度。因此，"不确定性如何度量"直接构成本文复现与拓展的方法论基础之一。

这支文献首先要处理的概念问题是"不确定性"与可观测"风险"（波动率）的区分。Jurado、Ludvigson 和 Ng（2015）做出了奠基性工作：先以自回归模型从大量宏观与金融序列中提取"不可预测成分"，再计算其条件波动率并聚合为宏观不确定性指数，从而把不确定性从可观测波动率中剥离出来；他们发现不确定性冲击具有独立的宏观效应。Ludvigson、Ma 和 Ng（2021）将该方法扩展到金融不确定性，发现金融不确定性领先于宏观不确定性且其冲击具有收缩性。与之互补，Baker、Bloom 和 Davis（2016）开创了文本路线：基于主流报纸构建经济政策不确定性（EPU）指数，目前已覆盖包括中国在内的二十余个经济体。在定价层面，Bali 等（2021）发现宏观不确定性风险在美国公司债市场享有显著溢价，将不确定性文献与收益预测直接连接起来——这正是 Bell 等（2026）将不确定性变量纳入预测方程的先导证据。

度量方法向中国的移植主要沿文本路线推进，其中既有方法修正也蕴含国情因素。Huang 和 Luk（2020）指出基于《南华早报》的早期中国 EPU 指数存在代表性偏差——香港报纸无法代表内地的政策信息环境——转而基于十份内地主流报纸构建了改进版中国 EPU 指数，并给出财政、货币、贸易等分项；Zhu（2018）相应构造了中国财政与货币政策不确定性指数。围绕这些指数，国内研究系统考察了经济政策不确定性对中国企业行为的实际影响：张成思和刘贯春（2018）基于经济政策不确定性与融资约束异质性视角考察了实业部门的投融资决策机制，发现不确定性上升显著抑制实体企业投资，且效应随融资约束强弱呈现明显异质性；顾夏铭等（2018）则发现经济政策不确定性对企业研发投入与专利产出反而具有促进作用，机制与实物期权价值相关。这些证据表明，政策不确定性已经实质性地进入中国企业的决策函数；至于它是否同样进入 A 股的收益生成过程并与个股特征交互，则是本文要回答的问题。但两点空白清晰可见：其一，Jurado-Ludvigson 式的"不可预测成分"不确定性指数尚无成熟的中国版本，需要研究者自行构建；其二，**将不确定性变量纳入高维收益预测框架、并刻画其与个股特征交互作用的研究，目前只有 Bell 等（2026）一例（且基于美国数据）**。考虑到中国政策驱动的市场特征——政策不确定性对 A 股风险溢价与交易行为的影响可能被散户结构放大——这一空白构成本研究重要的理论动机，也是本文计划自建中国版不确定性指数并检验其交互效应的直接依据。

### （四）中国 A 股市场的收益可预测性与制度环境研究

本研究的"落地场景"是 A 股，因此需要单独交代中国市场自身的因子体系、异象证据与制度约束——这三者共同决定了本文的样本设计、特征构造与组合形式，是必须结合国情处理的部分。

因子体系方面，直接套用美式因子在 A 股存在系统性偏差。Liu、Stambaugh 和 Yuan（2019）发现市值最小的 30% 股票受"壳价值"污染严重，据此重构了 A 股三因子模型（CH-3）：以流通市值底部 30% 界定小市值组合以剥离壳价值，以盈利市价比构造价值因子，CH-3 对 A 股横截面收益的解释力显著优于美式 Fama-French 三因子；加入换手率因子的 CH-4 进一步吸收了 A 股特有的高换手溢价。Wang（2026）将 CH-3 的检验扩展为跨越二十五年的复现，考察其解释力在市场制度变迁中的稳定性——这为本文复现式研究设计本身提供了同类先例。

异象证据方面，A 股呈现出与美股截然不同的结构。Shi 和 Zhou（2017）发现 A 股的横截面动量与反转效应随时间此消彼长，反转整体占优；Yao 等（2019）与 Hoang（2023）分别确认了特质偏度与最大日收益（MAX）所代表的博彩偏好定价；Chen（2017）证明网络搜索频率所反映的散户关注度伴随显著的反应过度；Liu 等（2026）将文本"语义漂移"引入 A 股横截面定价。这些证据与 Leippold、Wang 和 Zhou（2022）在机器学习框架下"流动性类特征主导"的发现互为印证：**A 股的可预测性大量来自散户交易行为与流动性结构，而非美股式的动量与风险因子**——这预示玻璃盒模型在 A 股揭示出的形状函数与交互结构，很可能与美国证据存在系统差异，构成本研究的核心科学问题。

制度环境方面，两类约束直接内生于本文的研究设计。其一是涨跌停制度：Wan 等（2015）刻画了涨停前的价格微观动力学，Wan 等（2018）发现涨跌停存在"冷却效应"；对预测研究更为关键的是 Zhang 和 Wang（2026）指出的问题——涨跌停使观测到的日收益构成**截断分布**（涨停日收益是潜变量被审查后的实现值），忽略这一结构的深度学习模型会产生系统性偏差，他们据此提出将价格约束显式嵌入损失函数。本文以月度收益为预测目标可在很大程度上规避高频截断问题，但涨跌停仍然约束组合的可执行性（涨停无法买入、跌停无法卖出）。其二是卖空约束：Miller（1977）的经典分析表明异质信念加卖空限制将系统性抬高股价；Su 等（2022）利用融资融券标的扩容的自然实验确认了卖空约束对 A 股定价效率的影响。这意味着美式研究惯用的十分位多空组合在 A 股只能以"多头指数增强 + 股指期货对冲"或"择时"的形式落地——本文在组合层面的设计必须正面处理这一约束，而不能照搬源论文的多空框架。

### （五）文献述评

综合上述四个方向，可以形成四点判断。第一，机器学习收益预测的方法体系已经成熟：从美股到 A 股再到新兴市场与债券市场，证据一致表明非线性与特征交互是样本外可预测性的主要来源。第二，"精度—可解释性"的传统权衡正在被打破：以 EBM 为代表的玻璃盒模型在多个高风险领域逼近黑盒精度，Bell 等（2026）首次将其引入资产定价即取得与随机森林相当的样本外 R²（12.10%），并证明显式形状函数优于 SHAP 事后归因；但这一框架**尚未离开美国公司债市场**，A 股横截面预测领域仍是空白。第三，Bell 等（2026）揭示的最强预测源——不确定性变化及其与特征的交互——在度量上已有 Jurado-Ludvigson 与文本法两条成熟传统及中国本土化进展，但"不确定性进入机器学习框架并与个股特征交互"在中国市场完全没有答案；考虑到 A 股散户主导、政策驱动的结构，该效应是否存在、是否被放大，是具有重要理论价值的开放问题。第四，A 股的制度环境（涨跌停截断、卖空约束）对预测建模与组合落地均构成现实约束，严谨的本土化研究必须将其内生于研究设计而非事后处理。

据此，本研究以 Bell 等（2026）为复现对象，将玻璃盒机器学习（EBM）框架迁移至中国 A 股：构建"公司特征 + 本土因子（CH-3/CH-4 等）+ 中国不确定性变量（EPU-China、自建 Jurado-Ludvigson 式指数）"的月度预测体系，系统检验（i）EBM 相对线性模型与黑盒模型的样本外精度；（ii）收益与特征关系的非线性、不对称性与交互结构，特别是"不确定性 × 特征"交互的中国证据；（iii）显式形状函数支持的、符合 A 股做空约束的可执行组合构造（多头指数增强与 EBM-pos 择时）。本研究既填补玻璃盒机器学习在 A 股应用的空白，也为"机器学习预测为何有效"提供显函数层面的经济学证据。

## 四、研究目标

本研究的总体目标是：以 Bell 等（2026）为蓝本，将"精度赛马—结构读取—组合构造"的玻璃盒机器学习预测范式完整迁移至中国 A 股，回答"精度、结构、落地"三个递进问题，为 A 股提供首个可解释、可执行、可审计的机器学习收益预测框架。研究的具体目标包括：

（1）构建"A 股公司特征（参照 Leippold、Wang 和 Zhou，2022）+ 本土因子（CH-3/CH-4）+ 中国不确定性变量（EPU-China 与自建 Jurado-Ludvigson 式指数）"的月度预测数据体系，完成数据质量审计与描述性分析；

（2）完成 EBM 与惩罚线性、随机森林、XGBoost 等基准模型的样本外精度比较，检验玻璃盒范式"精度无损失"命题在 A 股的稳健性；

（3）读取并检验 A 股收益生成的非线性、不对称与交互结构，特别是"不确定性 × 个股特征"交互的存在性、方向与经济含义；

（4）构造符合 A 股制度约束的可执行组合（多头指数增强、股指期货对冲、EBM-pos 择时），完成费用、稳健性与典型事件期的全面检验。

## 五、研究内容

本研究内容具体包括以下几个方面：

（1）**A 股收益预测问题与玻璃盒方法的一般性分析**。梳理机器学习收益预测与可解释性研究的发展脉络；构建特征库与不确定性变量；在样本期内做描述性统计，刻画 A 股收益、流动性特征与不确定性指数的长期图景及二者的关联规律。以上内容可视为本研究的现实背景。

（2）**研究假设的提出与机制分析**。本文以经验研究为主，不构造一般均衡理论模型，而是从不确定性定价与市场制度两条线索推演假设：其一，不确定性风险在资产定价中享有溢价（Bali 等，2021），不确定性回落时前期承压资产存在修复期权（Bell 等，2026 的公司债证据）；其二，A 股散户主导的结构放大政策信息的交易含义（Liu、Stambaugh 和 Yuan，2019；Leippold、Wang 和 Zhou，2022）；其三，卖空约束与涨跌停限制改变可执行策略的集合（Miller，1977；Su 等，2022；Zhang 和 Wang，2026）。据此提出五个假设：**H1**（精度）EBM 的 A 股月度样本外 R² 与随机森林、XGBoost 相当，显著优于惩罚线性模型；**H2**（流动性结构）最重要的形状函数属于流动性/反转类特征，且呈显著非线性与不对称性；**H3**（不确定性梯队）中国不确定性变化变量进入 A 股预测变量第一梯队，其加入带来显著的样本外增量 R²；**H4**（交互）"不确定性 × 流动性/波动特征"交互贡献显著增量，方向为不确定性回落时高流动性风险股票超额反弹；**H5**（组合）最高十分位多头组合扣除费用后的年化超额收益显著为正，EBM-pos 择时显著降低典型下跌期间的最大回撤。

（3）**实证分析Ⅰ：玻璃盒模型的样本外精度**。以扩张窗口逐月（或逐季，视计算量定）滚动训练 EBM 与各基准模型，报告个股层面月度样本外 R²、十分位组合收益的单调性与区分度、变量重要性排名，并与 Leippold、Wang 和 Zhou（2022）、Bell 等（2026）的对应结果对照，给出 A 股版的"精度赛马"证据。

（4）**实证分析Ⅱ：收益生成结构的显式读取**。这是本文的核心创新章节。逐个绘制并解读关键特征的一维形状函数（识别非线性、阈值与不对称性）；以 FAST 算法提取的二维交互项为重点，读取"不确定性 × 流动性/波动/规模"的中国版本；对交互效应实施三重统计检验（bootstrap 置信带、去除交互项的消融增量 R²、按交互贡献排序的组合收益检验）；并在相同样本上以 SHAP 解释随机森林，与 EBM 显式结构对照，提供事后解释可靠性的间接证据。

（5）**组合构造、稳健性与结论建议**。构造最高十分位多头指数增强组合（对中证 800 或中证全指报告超额、信息比率、跟踪误差与最大回撤）、纸面多空对照与"多头 + 股指期货空头"对冲组合、EBM-pos 择时策略；在 2015 年股市异常波动、2018 年中美贸易摩擦、2020 年新冠疫情与 2024 年初微盘股事件四个典型期间检验择时表现；完成费用敏感性、壳价值剔除、分时段、特征分层加入（仅公司特征→加市场宏观→加不确定性变量）等稳健性检验；最后总结结论并提出对量化监管、长线资金配置与投资者保护的建议。

根据以上研究内容，拟将论文划分为绪论、文献综述与理论基础、数据与变量、研究设计与方法、实证分析Ⅰ（精度检验）、实证分析Ⅱ（结构读取）、组合分析与可执行性、稳健性检验、结论与政策建议共九个部分。

## 六、拟解决的关键问题

（1）**中国版不确定性指数的构建与检验**。Jurado-Ludvigson 式指数在中国尚无成熟版本，序列集合的选取（覆盖哪些宏观金融维度、多少条）、自回归设定（阶数选择、滚动窗口长度）、条件波动率估计方式（滚动标准差 vs GARCH）与聚合方法（等权 vs 因子加权）均需自行决策，且需设计指数合理性的检验方案（与 EPU-China 的相关性、对产出与股市波动的预测力）。

（2）**高维月度面板上 EBM 的训练与样本外验证协议**。约 4000 只股票、20 年、近百个特征的月度面板对 EBM 的训练提出了计算与统计双重挑战：重估频率（逐月 vs 逐季）、交互项搜索空间的控制（最大交互对数）、超参数在训练窗内的交叉验证、以及严格的防前视设计（财务数据按公告日滞后、特征月末构造预测下月、样本外区间不参与任何模型选择）。

（3）**交互效应的统计推断**。Bell 等（2026）未提供交互项显著性的标准检验。本文需要构造并论证"bootstrap 置信带 + 消融增量 R² + 排序组合检验"三重流程的合理性：bootstrap 重复训练的次数与计算可行性、交互贡献的度量方式（二维形状函数方差占模型总方差的比重）、三重证据不一致时的解释框架。

（4）**制度约束下组合的可执行性评估**。卖空约束下多空组合的替代落地（指数增强/期货对冲/择时三种形态的适用条件）、涨跌停与停牌对调仓的成交调整（无法成交时顺延至下一可交易日）、交易费用假设（佣金、印花税、冲击成本）的设定依据与敏感性、以及策略容量与容量的粗略评估。

## 七、研究方法

本文采用理论分析和实证分析、定性分析与定量分析相结合的研究方法，主要基于公开市场数据，在文献回顾与假设推演的基础上，对玻璃盒机器学习在 A 股收益预测中的精度、结构与组合价值进行系统检验。选择的主要研究方法是：

（1）**文献分析法**。系统阅读机器学习收益预测、可解释机器学习、不确定性度量与 A 股市场制度四个方向的国内外文献并进行分类整理，为研究定位、变量选择与研究设计提供依据。

（2）**实证分析法（面板机器学习预测）**。以"股票—月度"面板为对象，用扩张窗口滚动训练 EBM 与基准模型，以样本外 R²、组合收益与显著性检验评估预测性能；这是本文的主体方法。

（3）**比较研究法**。一是模型间比较（EBM vs 惩罚线性 vs 随机森林 vs XGBoost）；二是市场间比较（本文结果与美国、A股已有证据的系统对照，识别散户结构带来的差异）；三是分时段与分子样本比较（机构化前后、剔除壳价值前后、事件期内外）。

（4）**典型事件分析法**。选取 2015 年股市异常波动、2018 年中美贸易摩擦、2020 年新冠疫情与 2024 年初微盘股流动性事件四个典型期间，检验不确定性指数信号、形状函数结构与 EBM-pos 择时策略在市场极端状态下的表现，为统计结果提供经济叙事。

## 八、设计及实验方案（研究方案）

### （1）数据选取与样本

研究对象为上海、深圳证券交易所全部 A 股上市公司，样本区间为 2005 年 1 月至 2025 年 12 月（以数据获取时点为准适当延长；自股权分置改革后起算以保证价格机制的市场化）。参照 Leippold、Wang 和 Zhou（2022）的规则筛选样本：剔除上市不满六个月、ST/PT 及长期停牌股票；金融股是否剔除以稳健性检验对照处理。行情与财务数据来自 CSMAR，宏观数据来自 Wind 与中经网，债券收益率曲线数据来自中债登。所有特征在每月末构造，用于预测下月收益；财务报表项目按公告日期滞后至少一个月，避免前视偏差。

### （2）变量构建

**被解释变量**：个股月度收益（相对一个月期国债收益率的超额收益，稳健性中使用原始收益）。

**公司特征**：以 Leippold、Wang 和 Zhou（2022）公开的 94 个特征清单为蓝本，从 CSMAR 逐月构造（数据缺失严重者剔除，最终特征数以数据审计结果为准），涵盖估值、盈利、投资、动量与反转、流动性、波动率与偏度等类别；特征做横截面排名标准化并做 1% 缩尾。

**市场与宏观变量**：市场股息率、市场方差、市场换手、期限利差（10 年期与 1 年期国债收益率之差）、信用利差（AA 级与 AAA 级企业债到期收益率之差）、通胀与货币增速等，对应源论文的市场与宏观变量模块。

**中国不确定性变量（本文自建构件）**：其一，直接采用 Huang 和 Luk（2020）的中国 EPU 指数（公开下载）及其财政、货币分项；其二，参照 Jurado、Ludvigson 和 Ng（2015）自建中国宏观不确定性（UNC）与金融不确定性（UNCf）指数——从 Wind 宏观数据库选取覆盖产出、价格、货币信贷、利率汇率、消费投资与房地产等维度的百余条月度序列（样本尽量回溯至 2000 年以前），统一频率与季节调整后，对每条序列以滚动窗口估计 AR(p) 模型（阶数按 BIC 选择），取预测误差为"不可预测成分"，计算其条件波动率并标准化，再分别以宏观序列与金融序列聚合（等权为主、因子加权作稳健性）得到两个指数；指数合理性以与 EPU-China 的相关性、对工业产出与股市波动的预测力检验。预测变量取指数的水平与一阶差分（ΔUNC、ΔUNCf），与 Bell 等（2026）保持一致。

### （3）模型设定与训练协议

**EBM（可解释提升机）**：模型为加法结构 y = g₀ + Σⱼ fⱼ(xⱼ) + Σₖ fₖ(xⱼ, xₗ)，其中一维形状函数 fⱼ 与选定交互对的二维形状函数 fₖ 均为阶跃函数，可绘图、可读取、可给出置信区间；训练采用循环梯度提升，交互项由 FAST 算法从残差中筛选，最大交互对数控制在合理范围（如前 10 对，敏感性分析对照）。**基准模型**：LASSO、弹性网络、随机森林、XGBoost，及可选的三层神经网络（NN3）；超参数一律在训练窗内交叉验证选择，样本外区间不参与任何模型选择。**样本外协议**：以 2005 年 1 月至 2012 年 12 月为初始训练窗，自 2013 年 1 月起以扩张窗口逐月（计算量受限时逐季，稳健性中对照两种频率）重估模型并产生下月个股预测，直至样本期末。

### （4）实证分析Ⅰ：精度检验

报告各模型的个股月度样本外 R²（预测与实现收益的横截面相关）、按预测收益十分位分组的等权组合收益及其单调性、多空价差，以及 EBM 的变量重要性（各形状函数方差占总方差的比重）；将结果与 Leippold、Wang 和 Zhou（2022）、Bell 等（2026）的对应表格并排对照，检验 H1—H3。其中"特征分层加入"设计（仅公司特征 → 加入市场宏观变量 → 加入不确定性变量）直接用于检验 H3 的增量贡献。

### （5）实证分析Ⅱ：结构读取与交互检验

绘制并解读全部高重要性特征的一维形状函数，识别非线性形态（单调性、阈值、饱和）与不对称性（分布左右尾贡献差异）；提取 FAST 交互项并重点解读"不确定性变量 × 流动性/波动/规模"的二维形状函数。交互效应实施三重检验：（a）对训练样本重复抽样（如 200 次）重训 EBM，构造形状函数与交互贡献的 bootstrap 置信带；（b）消融检验——去除全部交互（退化为纯 GAM）与逐对去除关键交互，报告样本外 R² 的变化；（c）经济检验——按交互项预测贡献排序构造组合，检验超额收益的显著性。另在相同样本上以 TreeSHAP 解释随机森林与 XGBoost，比较其归因与 EBM 显式结构的一致程度，为"事后解释 vs 玻璃盒"提供中国样本的对照证据。

### （6）组合构造与可执行性

每月末按预测收益排序分十组，等权持有（市值加权作稳健性）。可执行性处理：（i）最高组多头组合作为指数增强，对中证 800（或中证全指）报告年化超额收益、信息比率、跟踪误差与最大回撤；（ii）多空组合仅作纸面对照并注明不可直接执行，另构造"多头 + 股指期货空头"的对冲组合作补充；（iii）EBM-pos 择时——当市场聚合预测收益为负时转入货币市场工具，重点报告四个典型事件期间（2015、2018、2020、2024 年初）的回撤表现；（iv）费用与成交——设佣金、印花税（卖出 0.05%，提交前核对现行税率）与按成交额比例的冲击成本，参数参照国内实务与 Leippold、Wang 和 Zhou（2022）的设定，报告费用敏感性；调仓日遇涨停（无法买入）或跌停/停牌（无法卖出）时顺延至下一可交易日成交，并报告该调整对净值的边际影响；（v）以最高组换手率与中位日成交额粗略估算策略容量。

### （7）稳健性检验

（i）剔除流通市值底部 30%（壳价值污染，Liu、Stambaugh 和 Yuan，2019）后重估全流程；（ii）样本分段：2013—2018 与 2019—2025（机构化前后）；（iii）费用与换手敏感性；（iv）不确定性指数的替代构造（AR 滚动窗口长度、聚合方式、仅用 EPU 替代自建指数）；（v）EBM 超参数与重估频率敏感性；（vi）预测目标替代（原始收益、剔除市场成分的残差收益）。

### （8）技术路径

研究技术路径概括为四阶段流水线：数据工程（特征库与自建不确定性指数 → 质量审计）→ 建模（EBM 与基准模型的扩张窗口滚动训练 → 样本外预测）→ 结构分析（形状函数与交互提取 → 三重统计检验 → SHAP 对照）→ 组合落地（十分位构造 → 指数增强/对冲/择时 → 费用、成交与容量评估）。正式开题通过后绘制技术路径图。

## 九、可行性分析

（1）**数据可获得性**：本研究所需的行情与财务数据（CSMAR）、宏观数据（Wind、中经网）与债券收益率（中债登）均可通过学校订购的数据库获得；EPU-China 指数由 Huang 和 Luk（2020）项目网站公开提供；EBM 的实现（微软 InterpretML）与全部基准模型均为开源软件；Leippold、Wang 和 Zhou（2022）的 94 特征清单公开可复用。自建不确定性指数所需宏观序列在国内数据库中均有长期覆盖。数据与工具链的可获得性有充分保障。

（2）**研究者基础**：本研究要求金融计量、机器学习与大样本数据处理能力，作者已系统学习金融经济学、计量经济学与机器学习相关课程，具备 Python 数据分析与建模的编程基础。

（3）**指导与资源条件**：本研究由导师全程指导，导师组内有多名博士、硕士研究生可交流协作；依托单位具备 CNKI、万方、Wind、同花顺、国泰安等数据库资源，为研究的顺利开展提供可靠保证。

## 十二、创新点

（1）**研究视角创新**：首次将玻璃盒机器学习（EBM）引入中国 A 股横截面收益预测，将研究问题从"机器学习能否预测收益"推进到"收益生成结构能否被显式读取"，填补 Bell 等（2026）之后玻璃盒范式在中国市场的空白。

（2）**研究内容创新**：自建中国版 Jurado-Ludvigson 式宏观与金融不确定性指数，并将其纳入高维预测框架，提供"不确定性 × 个股特征"交互的 A 股证据；构造"bootstrap 置信带 + 消融增量 R² + 排序组合"的交互效应三重检验流程，补充源论文未解决的统计推断问题。

（3）**研究落地创新**：在卖空约束与涨跌停制度下设计可执行组合形态（多头指数增强、股指期货对冲、EBM-pos 择时），以扣除费用后的净超额收益为最终检验标准，正面回应机器学习预测"统计显著不等于经济显著"的方法论争议，使结论对长线资金与监管实践具有直接参考价值。
